# ECON487
*Applied econometric analysis suitable for roles in data science, economic consulting, market research, and quantitative analysis.*
This repository contains implementations of modern econometric and machine learning techniques applied to real-world economic problems including demand estimation, price elasticity analysis, market segmentation, and consumer behavior modeling.


## Key Projects

### Price Elasticity Estimation with DoubleML
- Implemented Double Machine Learning for causal inference on orange juice pricing data
- Estimated own-price and cross-price elasticity matrix using XGBoost for nuisance parameters
- Controlled for confounding using store/week fixed effects and demographic variables
- **Technologies:** DoubleML, XGBoost, statsmodels, pandas

### Demand Analysis & Market Design
- Analyzed adverse selection and price discrimination in differentiated product markets
- Built predictive models for consumer segmentation and revenue optimization
- Applied Random Forest and gradient boosting for non-linear demand estimation
- **Technologies:** scikit-learn, Random Forest, XGBoost

### Regularization & Feature Selection
- Implemented LASSO regression for high-dimensional econometric problems
- Applied Ridge regression and cross-validation for model selection
- Feature engineering including lag structures and interaction terms
- **Technologies:** scikit-learn, cvxopt

### Retail Analytics
- Time series analysis of sales data with lagged features
- Customer segmentation and revenue analysis
- Predictive modeling for demand forecasting
- **Technologies:** pandas, polars, seaborn, matplotlib
